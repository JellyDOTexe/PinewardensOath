# Pinewarden's Oath

Ten weapons for the Black Forest, made from bronze, core wood and troll hide, each one finished with an Ancient Seed from the Elder's woods. Every piece has its own model and does a little bit of fire damage.

This is the second set after First Thunder's Oath. The fire is there because greydwarfs and the Elder hate it, so the set is at its best in the forest it's named after. Trolls take it normally and draugr shrug it off, so don't expect it to carry you through the swamp.

Made with help from Claude.

## What you get

Everything is crafted at a level 2 forge. Each piece needs bronze, core wood, troll hide and one Ancient Seed. Upgrades cost half the bronze and core wood plus one troll hide, no seeds.

- Conekeeper - mace, 42 blunt
- Needle of the Watch - sword, 42 slash
- Rootcleaver - axe, 46 slash
- Towerroot - one-handed war pike, 46 pierce (see below)
- Elder's Knuckle - sledge, 46 blunt
- Boughreaper - atgeir, 52 pierce
- Seedfast - round shield, 28 block (+6 per level)
- Pathfinder's Thorn - dagger, 14 slash + 14 pierce
- Farwatch - throwing spear, 42 pierce. It flies with its own model and you pick the same one back up.
- Stillbough - bow, 36 pierce

Every weapon also does 5 fire damage, +1 per upgrade level. The pike, sledge and atgeir cost 10% less stamina than normal.

Animations and sounds come from the vanilla weapon each one is based on.

## The war pike

The pike is built on the Elder war pike from Therzie's Warfare, so with Warfare installed you get its moveset (one-handed, Spears skill). I took out the spirit damage it normally has since fire is this set's thing. Without Warfare it still works, it just acts like an atgeir.

## Install

Use a mod manager, or copy the `plugins` folder contents into `BepInEx/plugins/PinewardensOath`. The `assets` folder has to stay next to the DLL.

Needs Jotunn.

## Multiplayer

It adds items, so everyone on the server needs it, and so does a dedicated server.
